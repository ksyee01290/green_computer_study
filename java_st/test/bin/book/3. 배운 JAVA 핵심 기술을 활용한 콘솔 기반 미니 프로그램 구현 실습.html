도서 관리 시스템 요구사항 명세서

1. 프로젝트 개요

본 문서는 Java의 핵심 문법(Class, Interface, Array, File I/O)을 활용한 콘솔 기반 도서 관리 시스템의 요구사항을 정의합니다. 사용자는 터미널 환경에서 도서를 등록 및 조회할 수 있으며, 데이터는 텍스트 파일에 영구적으로 보존됩니다.

2. 비기능적 요구사항

본 프로그램은 객체지향 설계의 기초를 다지기 위해 다음 기술적 요소들을 반드시 포함해야 합니다.

클래스 (Class) 객체지향의 캡슐화 원칙에 따라 데이터 필드는 private으로 선언하고 Getter/Setter를 통해 접근합니다.
인터페이스 (Interface) 구현체와의 결합도를 낮추기 위해 시스템의 주요 기능을 추상 메서드로 정의한 인터페이스를 사용합니다.
배열 (Array) 컬렉션 프레임워크(List)를 사용하거나, 고정 크기의 객체 배열 Book[]을 사용하여 데이터를 관리합니다.
파일 입출력 (File I/O) java.io 패키지를 사용하여 텍스트 파일(.txt 형식)에 데이터를 읽고 쓰는 로직을 구현합니다.

3. 기능적 요구사항

요구사항-01 데이터 초기화 (Load)

프로그램 실행 시 books.txt 파일을 검색하여 기존에 저장된 도서 데이터를 읽어와 배열에 할당합니다

R요구사항-02 도서 정보 등록 (Add)

사용자로부터 도서 번호, 제목, 저자명을 입력받아 Book 객체를 생성하고 배열의 다음 빈칸에 저장합니다. 배열이 가득 찬 경우 적절한 예외 메시지를 출력합니다.

요구사항-03 전체 목록 조회 (List)

현재 배열에 저장된 모든 도서 리스트를 콘솔에 표 형태로 출력합니다. 저장된 도서가 없을 경우 "등록된 도서가 없습니다"라는 안내 문구를 표시합니다.

요구사항-04 데이터 보존 및 종료 (Save & Exit)

프로그램 종료 시 현재 배열에 있는 모든 데이터를 books.txt 파일에 다시 기록(Overwrite)하여 데이터의 영속성을 보장합니다.

4. 시스템 설계 상세

4.1. 인터페이스 정의

public interface Manageable {
    void addItem(Book book);    // 데이터 추가
    void displayAll();          // 전체 목록 출력
    void saveToFile();          // 파일로 데이터 저장
    void loadFromFile();        // 파일에서 데이터 로드
}

4.2. 데이터 모델 (Book Class)

  • id: int (도서 식별 번호)
  • title: String (도서 제목)
  • author: String (저자명)
  • toFileString(): 저장 시 사용할 CSV 포맷 문자열 반환 메서드
